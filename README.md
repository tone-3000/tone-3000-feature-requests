# TONE3000 Feature Requests

Public inbound for the **TONE3000 website** at [tone3000.com](https://www.tone3000.com).
Open an issue here to report a bug or request a feature.

There is no code in this repo. It exists so reports and requests are public and
searchable. Please search existing issues first, and add a 👍 or a comment if
yours is already there.

## What belongs here

Anything about tone3000.com itself: search, tone pages, uploads, accounts,
downloads, site copy, or a feature you wish existed. If you are not sure where
something goes, open it here and we will move it.

## What belongs somewhere else

Some parts of TONE3000 have their own repos, and the NAM projects we build on
are maintained upstream.

| If your issue is about | File it at |
| --- | --- |
| The TONE3000 plugin (VST3, AU, CLAP, Standalone, DAW behavior) | [tone-3000/tone3000-plugin](https://github.com/tone-3000/tone3000-plugin/issues) |
| The in-browser tone player (playback, model loading, DSP) | [tone-3000/neural-amp-modeler-wasm](https://github.com/tone-3000/neural-amp-modeler-wasm/issues) |
| NAM Core, the inference library | [sdatkinson/NeuralAmpModelerCore](https://github.com/sdatkinson/NeuralAmpModelerCore) |
| Training captures, or the NAM trainer | [sdatkinson/neural-amp-modeler](https://github.com/sdatkinson/neural-amp-modeler) |

The last two are upstream projects, not maintained by TONE3000.

For account questions, takedowns, or anything you would rather not discuss in
public, email [support@tone3000.com](mailto:support@tone3000.com).

## Writing a good issue

For bugs, the most useful details are the page URL, what you expected, what
happened instead, and your browser and OS. Console errors and screenshots help.

For feature requests, tell us what you are trying to accomplish, not just the
change you have in mind. The underlying goal often points somewhere better.
